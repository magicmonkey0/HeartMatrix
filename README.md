# HeartMatrix ❤️

<mark>COMING SOON!</mark>

An early exploration into interactive electronics, circuit prototyping, and physical user interfaces.

Built using an Arduino Uno, LEDs, resistors, and push buttons, the Heart Matrix board was an opportunity to experiment with LED patterns, button inputs, soldering and hands-on circuit construction.

This project marked one of my first steps into independently building electronic circuits and developing practical soldering skills.
